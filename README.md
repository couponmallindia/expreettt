# Expreet Autosphere Website
Premium 3-page static HTML5 website.

Pages:
- index.html
- services.html
- contact.html

Tech:
- HTML5
- CSS3
- Vanilla JavaScript

Brand logo:
- images/logo/expreet-autosphere-logo.jpg

Replace the SVG placeholder automotive imagery in images/hero and images/services with client-approved photographs when available.

Deploy:
1. Upload the complete folder contents to GoDaddy public_html.
2. Or push the folder to a GitHub repository and enable GitHub Pages.
3. Point www.expreett.com to the hosting/GitHub Pages configuration.
