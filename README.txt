EXPREETS TOURS & TRAVELS — MAINTENANCE WEBSITE

Files
- index.html: Main static HTML5 page
- style.css: Responsive layout and styling
- script.js: Small interaction for the “Check again” button
- assets/expreets-logo.jpeg: Provided company logo

Preview locally
1. Extract the ZIP.
2. Open index.html in a modern browser.

Upload to GoDaddy cPanel hosting
1. Sign in to GoDaddy and open cPanel for your hosting plan.
2. Open File Manager, then public_html (or the domain's document root).
3. Upload the ZIP and extract it there.
4. Ensure index.html is directly inside the document root, not buried in an extra folder.
5. Visit your domain and refresh the page.

Notes
- This is a static HTML5 website; no PHP or database is required.
- Keep the assets folder alongside index.html so the logo loads correctly.
- Google Fonts are loaded online; system fallback fonts are included.
- Replace the maintenance page with your live website when ready.
